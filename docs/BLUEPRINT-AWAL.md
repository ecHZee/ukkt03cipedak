# Tentang Organisasi

Karang Taruna RW 03 Cipedak adalah organisasi kepemudaan tingkat RW yang berada di Kelurahan Cipedak, Kecamatan Jagakarsa, Jakarta Selatan.

Karang Taruna ini berdiri pada 09 Juni 2025 dan memiliki masa bakti kepengurusan 2025-2028.

Data organisasi:

- 7 RT

- 59 anggota aktif

- ±60 kegiatan per tahun

Karang Taruna berfokus pada:

- Kegiatan sosial

- Pendidikan

- Olahraga

- Lingkungan

- Pengembangan masyarakat

- Publikasi kegiatan
