# Aturan Project

## DEVLOG wajib (append-only)

Setiap orang **dan setiap AI coding agent** (Lovable, Codex, Claude Code, Cursor, dll)
yang mengubah project ini **wajib**:

1. **Sebelum mulai:** baca `DEVLOG.md`, terutama section paling bawah, untuk tahu status terakhir.
2. **Setelah selesai:** tambahkan **satu section baru di paling bawah `DEVLOG.md`**
   memakai template yang ada di file tersebut.
3. **Dilarang** menghapus, menimpa, atau mengedit section lama. File ini **append-only**.
4. Satu sesi kerja = satu section. Waktu memakai format `YYYY-MM-DD HH:mm WIB` (UTC+7).

Field wajib tiap section: waktu, nama AI/orang, fase, ringkasan, daftar file yang berubah, status.

### English

`DEVLOG.md` in the repo root is a **mandatory append-only development log**.
Read the last section before you start. When you finish your changes, **append one new
section at the bottom** of `DEVLOG.md` following the template inside that file
(timestamp in WIB, your name/agent, phase, summary, changed files, status).
Never edit, overwrite, reorder, or delete existing sections — only append.

A change set without a matching new `DEVLOG.md` section is considered incomplete.
